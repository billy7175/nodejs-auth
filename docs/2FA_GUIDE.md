# 🔐 2FA 설정 가이드

## 📱 스마트폰에서 "이 확인 코드를 추가할 암호 선택"이 나올 때

### 이게 뭔가요?

Google Authenticator 앱에서 QR 코드를 스캔한 후 나타나는 **선택사항**입니다.

**의미:**
- 계정에 추가 암호를 설정하는 옵션
- Authenticator 앱 자체를 보호하기 위한 기능
- **선택사항이므로 건너뛰어도 됩니다** ✅

### 어떻게 해야 하나요?

**옵션 1: 건너뛰기 (권장)**
- "건너뛰기" 또는 "Skip" 버튼 클릭
- 바로 계정이 추가됩니다

**옵션 2: 암호 설정**
- 암호를 설정하면 Authenticator 앱을 열 때마다 암호 입력 필요
- 앱 자체 보안 강화 (선택사항)

**결론:** **건너뛰어도 됩니다!** 2FA 기능에는 영향을 주지 않습니다.

## 🔑 백업 코드란?

### 백업 코드의 역할

**스마트폰을 잃어버렸거나 Authenticator 앱을 삭제했을 때** 사용할 수 있는 **일회용 코드**입니다.

### 언제 사용하나요?

1. **스마트폰 분실/도난**
   - Authenticator 앱에 접근 불가
   - 백업 코드로 로그인 가능

2. **앱 삭제/재설치**
   - 계정 정보가 사라짐
   - 백업 코드로 2FA 비활성화 후 재설정

3. **기기 변경**
   - 새 기기로 옮길 때
   - 백업 코드로 임시 로그인

### 백업 코드 사용 방법

1. 로그인 시 OTP 코드 입력 화면에서
2. "백업 코드 사용" 또는 "백업 코드 입력" 클릭
3. 저장해둔 백업 코드 중 하나 입력
4. 로그인 완료

### ⚠️ 중요 사항

**백업 코드는:**
- ✅ **10개** 제공됨
- ✅ **일회용** (사용하면 소멸)
- ✅ **안전한 곳에 보관** 필수
- ❌ **다른 사람과 공유 금지**
- ❌ **스크린샷으로 저장하지 말 것** (클라우드에 업로드되면 위험)

### 백업 코드 보관 방법

**권장:**
1. **비밀번호 관리자** (1Password, LastPass 등)
2. **암호화된 파일** (USB 등 오프라인 저장)
3. **종이에 적어서 금고에 보관**

**비권장:**
- ❌ 스크린샷 (클라우드 동기화 위험)
- ❌ 이메일로 전송
- ❌ 메모 앱 (암호화되지 않은 경우)

## 📋 2FA 설정 전체 과정

### 1단계: QR 코드 스캔
1. "2FA 설정 시작" 버튼 클릭
2. QR 코드 표시
3. Google Authenticator 앱 열기
4. "+" 버튼 → "QR 코드 스캔"
5. QR 코드 스캔
6. **"이 확인 코드를 추가할 암호 선택"** → **"건너뛰기"** 클릭 ✅

### 2단계: OTP 코드 입력
1. Authenticator 앱에서 6자리 코드 확인
2. 웹 페이지에 코드 입력
3. "검증 및 활성화" 클릭
4. 2FA 활성화 완료! ✅

### 3단계: 백업 코드 저장
1. 화면에 표시된 **10개의 백업 코드** 확인
2. **안전한 곳에 저장** (비밀번호 관리자 권장)
3. 페이지를 닫으면 다시 볼 수 없음 ⚠️

## 🆘 문제 해결

### Q: 스마트폰을 잃어버렸어요
**A:** 백업 코드를 사용하여 로그인 후 2FA를 비활성화하고 재설정하세요.

### Q: 백업 코드도 잃어버렸어요
**A:** 관리자에게 문의하거나, 계정 복구 절차를 진행해야 합니다.

### Q: OTP 코드가 맞지 않아요
**A:**
- 시간 동기화 확인 (스마트폰 시간이 정확한지)
- 30초 이내에 입력 (코드는 30초마다 변경)
- 공백 없이 6자리 숫자만 입력

---

## 💡 팁

1. **백업 코드는 즉시 저장**
   - 페이지를 닫기 전에 반드시 저장
   - 나중에 다시 볼 수 없음

2. **여러 기기에 등록**
   - 같은 QR 코드를 여러 기기에서 스캔 가능
   - 여러 기기에 등록하면 더 안전

3. **정기적으로 백업 코드 확인**
   - 사용한 코드는 제거
   - 남은 코드 개수 확인
